fails when the rule is broken again. The point is the last two columns: a fix that is only a
fix gets undone by the next refactor, a fix that is also a test does not. The decisions behind
the rules are in the [decision log](decisions.md); the table below is checked by
[`tests/test_decision_log.py`](../tests/test_decision_log.py): every row cites a commit that
exists and a test that exists in the file it links.
